# 指间 · Finger Lab

一个手机优先的手指实时追踪原型。打开 `index.html` 可预览页面与演示动画；真实摄像头需要安全的浏览器环境。

## 功能

- 一只手的 21 个关键点、骨架和食指光标。
- 短时指尖轨迹、拇指与食指捏合反馈、五指弯曲程度估计。
- 前后摄像头切换、轨迹清除、骨架/轨迹/平滑开关。
- 实际处理帧率和单帧推理耗时；演示模式不显示虚构性能数据。
- 权限、HTTPS、网络加载错误提示；切到后台自动关闭摄像头。
- 图像仅在当前设备处理，无后端、无录制、无音频、无影像上传。

## 运行

无需 npm 或构建。电脑在项目目录运行：

```sh
python3 -m http.server 4179 --bind 127.0.0.1
```

在同一台电脑的浏览器打开 `http://localhost:4179`。

**手机真实摄像头测试：把 `index.html` 上传到支持 HTTPS 的静态托管，然后在手机 Safari 或 Chrome 打开 HTTPS 链接。** 手机不能用电脑的 `localhost`；普通局域网 HTTP 地址不满足摄像头的安全上下文要求。聊天客户端的文件预览或 iframe 可能没有摄像头授权，需要在系统浏览器单独打开。

## 依赖与限制

界面样式、业务脚本和矢量绘制均在单个 HTML 内。真正的手部识别需要联网加载固定版本的 MediaPipe Tasks Vision `0.10.21`（jsDelivr，组件加载失败时尝试 unpkg），以及 Google 官方 float16 手部模型版本 `1`。因此这是**单文件页面，不是离线识别包**。部署环境应允许加载这两个 CDN、Google 模型地址、WebAssembly，以及 blob module worker。

优先使用 Worker 处理识别，界面线程绘制；浏览器不支持时退回主线程 GPU/CPU。最多每秒提交 30 个新视频帧，忙时不排队。FPS 为完成处理的帧率；“单帧处理”仅为检测调用耗时，不是摄像头到屏幕的端到端延迟。

捏合使用指尖距离与掌宽的比值，并以不同的进入/退出阈值减少闪烁。弯曲程度由关节夹角估算，受遮挡、角度及模型误差影响，不用于精密测量。只追踪一只手；多只手同时出现可能导致追踪目标切换。

手机兼容性、发热、实际延迟及网络可达性仍需目标真机测试。前后切换最终取决于浏览器返回的摄像头；只有一只摄像头的设备可能仍使用同一镜头。

技术来源：[MediaPipe Web 文档](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。
